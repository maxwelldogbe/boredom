# Boredom frontend

React + TypeScript + Vite app for Boredom.

**Setup and run instructions are in the repo root [README.md](../README.md)** (steps 5–6 cover the
frontend). A full frontend README comes in phase F7.

Quick reference (from this folder, with the backend running on port 8000):

```bash
npm ci          # install (once)
npm run dev     # start at http://localhost:5173
npm run lint && npm run typecheck && npm test && npm run build
```
